# Imágenes de Certificaciones

Coloca aquí las imágenes de los certificados ISO con los siguientes nombres exactos:

| Archivo           | Descripción                          |
|-------------------|--------------------------------------|
| `iso-9001.png`    | Certificado ISO 9001 (Calidad)       |
| `iso-14001.png`   | Certificado ISO 14001 (Ambiental)    |

## Recomendaciones
- Formato: PNG o WebP con fondo transparente
- Tamaño sugerido: 400×400 px o superior
- Si no se encuentran las imágenes, la página mostrará automáticamente un badge con el número de la norma
